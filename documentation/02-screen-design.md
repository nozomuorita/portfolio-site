# 画面設計書

最終更新日: 2026-09-21

## 1. 画面構成

本サイトは、ページ遷移を行わない1ページ構成です。ヘッダー内リンクからHTMLのアンカーへ移動します。制作物の詳細だけ、ページ上にモーダル（重ねて表示する詳細画面）を開きます。

```text
固定ヘッダー
└─ Hero（氏名・導入・CTA）
   └─ About（人物像・経歴・研究）
      └─ Portfolio（制作物一覧 → 詳細モーダル）
         └─ Qualifications（資格）
            └─ Skill（使用技術）
               └─ Contactまたは連絡先導線
                  └─ Footer（外部リンク・先頭へ戻る）
```

## 2. 共通レイアウト

| 項目 | 仕様 |
| --- | --- |
| 最大コンテンツ幅 | Bootstrapのコンテナ幅を基準にし、広い画面でも本文を過度に広げない |
| 基本余白 | セクション上下に十分な余白を置き、情報群を明確に分ける |
| 見出し | 英字のセクション名を大見出しとし、必要な場合だけ短い補足を付ける |
| 配色 | 夜景に合う濃紺、白、淡い水色を基本色とする |
| フォント | 見出し・ナビゲーションはMontserrat系、本文は日本語可読性の高いsans-serif |
| スクロール | スクロール操作は維持する。スクロールバーは視覚上非表示でもよい |

## 3. セクション仕様

### 3.1 Header

**目的:** サイト内の主要情報へ素早く移動できるようにします。

| 要素 | 表示・動作 |
| --- | --- |
| ロゴ | 左側に表示し、選択するとHeroへ戻る |
| ナビゲーション | About、Portfolio、Qualifications、Skillを基本項目とする |
| BGMボタン | 採用する場合のみ表示。再生・停止状態を見た目とアクセシブル名で示す |
| スクロール時 | 背景色を濃くして、下のコンテンツ上でも文字を読みやすくする |
| モバイル | ハンバーガーメニューへ折りたたみ、項目選択後に閉じる |

**現状との差分:** `ACCOUNT`は移動先がないため、About内の外部アカウントと役割が重複しています。原則としてナビゲーションから削除します。

### 3.2 Hero

**目的:** 最初の数秒で、誰のポートフォリオかを伝えます。

| 要素 | 表示・動作 |
| --- | --- |
| 背景 | 都市夜景の動画。画面全面を覆い、中央基準でトリミングする |
| オーバーレイ | 文字の可読性を保つ暗色レイヤー |
| 補助見出し | `Welcome To My Portfolio`。氏名より小さく表示する |
| 氏名 | `NOZOMU ORITA`。最も強い視覚階層とする |
| CTA | `Tell Me More`と下向き矢印。選択するとAboutへ移動する |

横長画面ではHeroの高さをビューポート相当とします。縦長画面では動画の過剰な拡大・トリミングを避けるため高さを抑え、次のコンテンツが見えてもよいものとします。文字サイズは`clamp()`で連続的に調整し、大型モニターでも過大にならない上限を設けます。

動画が読み込めない場合に備え、同じトーンの静止画をposterとして表示します。OSの「動きを減らす」設定が有効な場合は、自動再生を止めて静止画を優先します。

### 3.3 About

**目的:** 人物像、経歴、研究活動を簡潔に伝えます。

| ブロック | 内容 |
| --- | --- |
| プロフィール | 周囲をぼかした画像、表示名`nzm_ort`、趣味3項目、AtCoder・Codeforcesへのリンク |
| 経歴 | 出身、高校、大学、大学院、社会人を時系列表示 |
| 学会発表 | 左に発表年月・会議名・発表名を時系列で表示し、右に受賞証明書を配置 |
| 学術論文 | 左に書誌情報と外部リンク、右に論文1ページ目のプレビューを配置 |

プロフィール画像は背景となじませ、カード枠で囲みません。本文量を増やしすぎず、詳細は外部リンクへ分離します。

### 3.4 Portfolio

**目的:** 制作物の種類と実装経験を、画像から直感的に理解できるようにします。

| 状態 | 表示・動作 |
| --- | --- |
| 一覧 | 画像、名称、1文の概要をカード形式で表示する |
| Hover/Focus | 詳細を開けることが分かる共通表現を使用する |
| 詳細モーダル | 名称、画像、説明、使用技術、GitHubまたは公開URLを表示する |
| 閉じる | 閉じるボタン、Escキー、モーダル標準操作で一覧へ戻る |

公開前に、GitHubリンクが存在しない制作物は「準備中」と明示するか、リンク表示自体を省きます。カード全体を`target="_blank"`にはせず、外部リンクだけを新しいタブで開きます。

### 3.5 Qualifications

**目的:** 保有資格と取得時期を見やすく一覧化します。

| 要素 | 仕様 |
| --- | --- |
| アイコン領域 | 全資格で同一の表示領域を確保する |
| 画像 | `object-fit: contain`を基本とし、ロゴ全体を見切れさせない |
| 資格名 | 2行になってもカード高さが大きくずれないようにする |
| 取得年月 | `YYYY年M月取得`に統一する |
| 並び順 | 取得年月の昇順または降順のどちらかに統一する。現状は昇順 |

### 3.6 Skill

**目的:** 使用経験のある技術を、採用担当者と技術者の双方に伝えます。

| 要素 | 仕様 |
| --- | --- |
| 技術アイコン | 同じ視覚サイズに調整する |
| 技術名 | 一般的な正式表記を使用する |
| 経験文 | 何に使ったかを1〜2文で記載する |
| 外部配信失敗 | CDN上のアイコンがなくても技術名は読めるようにする |

習熟度を数値や星だけで表すと基準が曖昧になるため、現段階では用途・経験による説明を採用します。

### 3.7 Contact / 連絡先

**現状:** 氏名、メール、電話、本文のフォームが表示されていますが、送信ボタンは無効で`Not working`と表示されます。

**初期リリースの推奨:** Contactフォームをいったん非表示にし、FooterまたはContactセクションにGitHubなど公開可能な連絡先だけを置きます。送信先と個人情報の扱いが決まってからフォームを追加します。

将来フォームを実装する場合は、次の状態を設計します。

- 未入力、入力中、入力エラー
- 送信中（二重送信不可）
- 送信成功
- 送信失敗と再試行
- 迷惑送信の拒否

### 3.8 Footer

**目的:** ページの終端を示し、外部プロフィールと先頭へ戻る導線を提供します。

| 要素 | 仕様 |
| --- | --- |
| 所有者名・著作権年 | 年は実行時に現在年を表示する |
| GitHub | 正式プロフィールを新しいタブで開く |
| Instagram | 正式URL設定後に表示する |
| Back to top | Heroへ戻る |

## 4. レスポンシブ仕様

| 区分 | 目安 | 主な変化 |
| --- | --- | --- |
| モバイル | 320〜575px | 1列、メニュー折りたたみ、文字と余白を縮小 |
| タブレット | 576〜991px | 1〜2列、内容に応じて画像と文章を縦積み |
| デスクトップ | 992px以上 | 複数列、固定ヘッダー、十分な左右余白 |
| 縦長画面 | aspect-ratioが概ね3/4以下 | Heroを約78svhまで抑え、次セクションの露出を許容 |

ブレークポイント直前だけでなく、その中間幅でも要素が自然に伸縮するよう、`min()`、`max()`、`clamp()`、Grid/Flexboxを使用します。

## 5. 操作・アクセシビリティ仕様

- アンカー移動時は固定ヘッダーで見出しが隠れないよう`scroll-margin-top`を設定する。
- クリック可能な要素には、HoverだけでなくFocus表示も付ける。
- アイコン単独ボタンには、日本語または英語の明確な`aria-label`を付ける。
- 装飾画像は空の`alt`、情報を持つ画像は内容を表す`alt`にする。
- モーダルを閉じた後は、開く前のカードへフォーカスを戻す。
- 色だけで状態を表さない。

## 6. SEO・共有表示

| 項目 | 目標値・内容 |
| --- | --- |
| HTML言語 | `ja` |
| title | `NOZOMU ORITA | Portfolio`など内容が分かる名称 |
| description | 経歴・制作物・資格を紹介するサイトであることを120字程度で記載 |
| OGP | title、description、image、URLを設定 |
| favicon | ロゴと統一した正方形画像 |
| 構造 | ページ内に主見出し`h1`を1つ置き、以降を階層化 |

## 7. 画面確認項目

1. 320px幅でナビゲーション、カード、モーダルが画面外へはみ出さない。
2. 1440px以上でHeroの氏名が大きくなりすぎず、背景とのバランスを保つ。
3. 縦長端末でHero動画の主要部分とCTAが確認できる。
4. 資格ロゴの端が切れず、異なる縦横比でも中央に収まる。
5. Contactを残す場合、送信不能な操作を有効に見せない。
